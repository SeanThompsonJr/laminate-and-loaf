# Laminate & Loaf: website design concept

A design concept by Sean Thompson for a **made-up** Jacksonville pastry shop. Every name, price, date, address and phone number is sample data, and nothing ordered on the site is sent or charged.

- `index.html`: the home page (illustrations, holiday favorites, how ordering works, FAQ, visit)
- `order.html`: online ordering for pickup or delivery
- Food photos: free photos under the Unsplash License, credited in `img/CREDITS.md`, each marked "Concept only"
- Illustrations: custom figures made with [Hairline](https://github.com/lucasmarkes/hairline) by Lucas Marques (MIT; see `hairline/LICENSE-hairline.txt`). Figure sources are in `hairline/src/`; run `node bundle.mjs` in `hairline/` after editing one.
